# ÀṢẸ — O Mundo Ainda Nasce

JRPG 2D em pixel art inspirado por cosmologias iorubás e afro-brasileiras, com narrativa original.

## Tecnologia

- Godot 4.7.1 Standard
- GDScript
- viewport interno de 640×360
- escala inteira recomendada: 1280×720 ou 1920×1080
- áudio em 48 kHz
- arte-fonte em Aseprite/Pixelorama e exportação PNG

## Abrindo o projeto

1. Instale Godot 4.7.1 Standard.
2. Importe o arquivo `project.godot`.
3. Aguarde a importação dos assets.
4. Execute com `F6` ou `F5`.

O projeto inicia em `src/core/boot/boot.tscn` e segue para `src/world/prologue/prologue.tscn`.

## Princípios

- O jogo apresenta uma obra ficcional, não uma reprodução de rito.
- Variantes de tradição não serão reduzidas a uma única versão universal.
- Elementos restritos ou iniciáticos não serão transformados em mecânica.
- Olódùmarè não será representado fisicamente.
- Exu não será tratado como figura demoníaca.
