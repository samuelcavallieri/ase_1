# Toolchain fixada

## Obrigatória

- Godot 4.7.1 Standard com export templates
- Git e Git LFS
- Aseprite ou Pixelorama
- FFmpeg
- Logic Pro no macOS e Ableton Live no Windows

## Política de versões

Todos devem usar a mesma versão minor do Godot. Atualizações de engine entram em branch própria e somente após abrir, executar, testar salvamento e gerar build de validação.

Nenhum addon de Godot será adotado sem licença registrada, versão fixada e justificativa técnica.
